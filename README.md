# HumanMachineInterface

Приложение для выполнения лабораторных работ №1 и №2 по дисциплине «Интерфейсы человек–ЭВМ».

## Установка и запуск

Рекомендуется Python 3.12.

```bash
python -m pip install -r requirements.txt
python main.py
```

## Лабораторная работа №1

Моделирование времени выполнения диалоговых маршрутов при различных вероятностях ошибочных действий оператора. Параметры маршрутов и эксперимента задаются на вкладке ЛР1.

## Лабораторная работа №2

Событийная имитационная модель системы с одним оператором и очередью заявок FIFO:

- поток заявок — пуассоновский, межприходные интервалы экспоненциальные с параметром интенсивности `λ`;
- время обслуживания штатной заявки формируется по маршрутам A1/A2 из модели ЛР1;
- при ошибке оператор повторяет текущий шаг, вероятность ошибки задаётся параметром `Pi`;
- поток отказов задаётся выбранным законом времени наработки на отказ;
- при отказе текущая и ожидающие заявки аннулируются;
- восстановление выполняется по маршрутам B1/B2 из модели ЛР1;
- заявки, поступившие во время восстановления, ожидают окончания восстановления;
- суммарные потери рассчитываются как `R1 × суммарная задержка заявок + R2 × время простоя`.

### Допущения для законов отказов

Методические указания требуют выбрать закон распределения времени наработки на отказ, но не задают параметры разброса для равномерного и нормального законов. Поэтому в приложении используются следующие допущения:

- экспоненциальный: среднее значение `m`;
- равномерный: `U(0, 2m)`;
- нормальный: `N(m, (0.1m)^2)` с отбрасыванием неположительных значений.

В методических указаниях не уточнено поведение заявок, поступающих уже во время простоя. В этой реализации они остаются в очереди и могут быть обработаны после восстановления. Это допущение следует явно указать в отчёте.
